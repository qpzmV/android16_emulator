trunk_staging是什么意思

Created 0 todos

`trunk_staging` 是 AOSP 的一个分支概念：

- **trunk** = Android 的主开发分支（相当于 Linux 的 mainline），包含最新的代码和功能
- **staging** = "暂存区"或"预发布版本"

**所以 `trunk_staging` = Android 主干的暂存/预发布版本**

它的作用：
1. **新代码验证** - 代码合并到主分支 (`trunk`) 前的测试环节
2. **持续集成** - 确保即将发布的代码能正常构建
3. **提前发现问题** - 在代码正式进入 trunk 之前发现 bug

**对你的影响：**
- `trunk_staging` 包含比较新的代码，可能比稳定分支不稳定
- 更容易接触最新功能和改进
- 如果你在学习或开发最新功能，这个分支很适合
- 如果你要做生产级别的东西，通常会用更稳定的分支（如 `android-X.X.X`）
